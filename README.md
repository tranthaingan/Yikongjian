# Yikongjian
SillyTavern Extension - Yikongjian
# ✨ 异空间 (Yikongjian)

一个为 SillyTavern（酒馆）打造的**重度沉浸式小剧场与多线剧情管理脚本**。

---

## 🌟 核心功能亮点

### 📁 强大的正文与文件管理
* **文件可视化**：直接读取酒馆聊天文件，显示条数与大小，支持自定义描述与 AI 生成摘要。
* **显示/隐藏区分离**：主显示区只留最大文件，其余自动收入隐藏区，列表瞬间清爽。
* **防误删机制**：重要正文文件可一键【锁定】，锁定后异空间绝不自动清理或移除。
* **快捷恢复**：直接通过异空间恢复聊天，无需绕回酒馆原生菜单。

### 🎭 独立且沉浸的小剧场 (Theater)
* **独立专属预设**：小剧场可读取酒馆 API 预设列表，**独立指定**一份专属预设。进入时自动切换，退出时恢复原样，且互不叠加，防止上下文污染。
* **专属演绎规则**：可自定义系统内置提示词，插入聊天末尾，确保角色不崩坏（如：形态决定行为、输出前自检）。
* **小剧场存档与归档**：退出小剧场自动存入独立存档，最多保留10个历史记录，随时点开继续演绎。
* **AI 生成小剧场**：支持一键让 AI 根据当前上下文生成小剧场标题、描述和世界观。

### 🧠 记忆互通 (Memory Sync)
* **跨线记忆融合**：支持将“正文文件”与“小剧场”自由组合（主体与次体），一键提取总结，合并进聊天副本。小剧场也可以完美融入主线记忆。

### 🎨 极致的视觉沉浸 (UI & CSS)
* **全自动昼夜美化**：进入小剧场时，根据当前时间（白天/夜晚），自动从你选定的美化作息中随机切换酒馆美化，退出自动换回。
* **顶部横幅自定义**：支持独立的小剧场顶部横幅，可遮挡原生图标。支持保存多份自定义 CSS，甚至能随机切换。
* **沉浸式氛围滤镜**：只在屏幕四周叠加一层面纱（支持自定义 CSS 粒子/光影），中间留空不影响阅读，氛围感拉满。

### ⚙️ 自由的底层配置
* 支持**独立自定义 API**（如 DeepSeek、Claude 等）用于总结和生成。
* 全局所有提示词（系统词、总结词、标题描述词）均可**完全编辑**与恢复默认。

---

## 🚀 安装与使用

1. 下载本仓库中最新的 `.json` 或 `.zip` 导入包。
2. 在酒馆（SillyTavern）的扩展页面（Extensions）中导入安装。
3. 刷新页面，点击酒馆菜单栏中出现的「✨ 异空间」浮标即可进入。
